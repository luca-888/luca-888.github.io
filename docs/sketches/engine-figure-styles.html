vLLM 引擎文章 · 图表风格 10 选 1

同一组内容（进程路径 / CUDA Graph 分派 / step 时间线，时间线用实测数据）换 10 种视觉语言。选定后按该风格重做 figure-kit 与全文五张图，并补夜间配色。

01鲜明实心

饱和实心色块 + 白字，淡色进程底带；最接近现有规范，只把颜色和字号拉开

02淡底描边

浅色填充 + 同色细描边 + 同色字，文档站常见的克制风格

03深色 IDE

深底，亮色块，关键路径发亮的橙；夜间模式天然好看

04新粗野

粗黑描边 + 硬投影 + 高饱和平涂，直角，很有冲击力

05蓝图

藏青底 + 网格 + 白色线框 + 等宽字，工程图纸感

06编辑印刷

米白纸底、宋体标题、墨黑 + 一种朱红强调，像杂志插图

07灰阶 + 单一强调

全部中性灰，只有关键路径 / 本例用亮橙，一眼看到重点

08马卡龙柔和

低饱和粉彩、大圆角胶囊、深色字，亲和不刺眼

09手绘草图

Excalidraw 式抖动线条 + 半透明填充，适合讲机制的“白板”感

10浮起卡片

白卡片 + 柔和阴影 + 彩色顶边，Apple / Vercel 式产品图

# 小红书图片输出

用户要求“生成小红书图片”时，输出全文正文阅读页；用户限定范围时按指定范围。封面与邮件发送不在此流程内，由用户自行处理。

## 正文阅读页

- 电脑端博客正文截图式排版，1080 × 1440 竖版 PNG；纯白底、左对齐，无浏览器外框和海报装饰。
- 左右边距约 72px，顶部约 62px；章节标题约 52px / 600 字重，正文约 36px / 1.62 行高，段间距约 26px；字体优先系统无衬线与 PingFang SC。（2026-09-29 用户要求压缩页数，由 40px / 1.68 调整而来）
- 页眉：左侧文章标题、右侧 `luca’s blog`，约 26px 辅助灰，下接细分隔线。页脚：当前章节与连续页码，细线分隔。
- 链接蓝灰色；引用为蓝灰文字加细左边线；重点适量加粗。文末“参考”一节不输出（图片中链接无法点击，用户 2026-09-29 要求去掉）；正文里的出处链接与引用保留。
- 按语义与完整段落分页，完整保留原文标题层级、顺序与信息，不删减正文。可加简短页面小标题，但不能替代原文章节标题。
- 编号章节大标题（“一、二、三……”）逐字保留，在该章首张图片的正文区域醒目展示，且与本章首段或首图同页；空间不足时整体移到下一页，不截短、不降级、不拆页。
- 插图保留原比例、就近排版，图注用小号辅助文字；不以缩小整页容纳溢出内容。

## 生成器

正文页由仓库内的生成器自动排版导出，不再每次手写 HTML：

```bash
npm run dev                                   # 另开一个终端保持运行
npm run xhs -- <slug>                         # 导出正文页、标题清单与 ZIP
node scripts/xhs/contact-sheet.mjs <slug>     # 生成整套缩略总览 preview.png
```

- 新文章先在 `src/xhs/articles.ts` 登记（复用文章的 `<slug>.blocks.tsx`：正文、标题与图表映射）。浏览器打开 `/xhs.html?slug=<slug>` 可直接预览全部页面。
- 排版复用站点的 Markdown、KaTeX、Shiki 与自绘图组件；样式在 `src/xhs/xhs.css`，分页逻辑在 `src/xhs/paginate.ts`。
- 分页规则：按真实高度装页；章节标题和以冒号结尾的引导句与下一块同页；段落按句、列表按项、代码按行拆分，前半段至少两行，剩余部分代码与列表至少两项、段落至少 12 个字；图表不拆，差一点放不下时缩小到 78% 以内留在本页，否则换页。
- 导出校验：分页前后正文文字逐字一致，否则导出失败；`outline.json` 记录各级标题所在页码，终端列出章节起始页与被缩小的块。
- 输出在 `xhs/<slug>/`（已 gitignore）：`01.png…`、`outline.json`、`preview.png`、`<slug>-xhs.zip`（仅含正文页）。

## 核对

导出后查看 `preview.png` 与每个章节起始页，确认标题完整醒目、无截断与异常空白；图内文字在手机上是否清楚；ZIP 页数与导出页数一致。

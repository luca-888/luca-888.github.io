# 小红书图片输出

用户要求“生成小红书图片”时，输出全文正文阅读页；用户限定范围时按指定范围。明确要求封面时按下面的封面规范生成；邮件发送不在此流程内。

## 封面

- 默认 9:16 长竖版（宽:高），不再沿用 3:4；“16:9 竖版”也按长竖版意图处理。仅明确要求横版时使用 16:9 横版。（2026-10-02 用户确认）
- 中英文同时出现，以中文大标题为主体，英文作为较小的辅标题；保留指定模型名副标题。
- 顶部约 12% 留作无文字安全区，左右文字边距至少约 6%；主体在下方充分展开，避免无必要的大块底部留白。
- 先读文章再提炼抽象视觉含义；用户要求先看概念时，确认后才生成。封面避免堆叠教学图编号、参数和性能数字。
- 核对并报告生成图片的实际尺寸与比例；目标尺寸不等于工具返回尺寸。定稿保存到 `covers/<slug>/`（平铺，不建子目录），连同提示词或绘制源文件一起进仓库；一个主题只留定稿，样稿和落选版本不保存。（2026-10-07 用户确认）
- **横版视频的封面单独出 4:3（1440 × 1080），内容用视频第一页，不另行设计**：信息流里横版封面按 4:3 显示，16:9 的画面会被居中裁掉左右各 1/8，直接截帧标题会被切掉。做法是把第一页的各个部分重新摆进 4:3（标题区左移、宽的图形按宽度缩小），内容不增不减；右上角约 1/8 宽的位置有播放图标，标题不要伸到那里。（2026-10-02 用户截图反馈；用户否定了重新设计的版本）

## 竖版视频

视频默认做横版，用户指定时才做竖版（2026-10-04 用户确认）。竖版尺寸如下（2026-10-03 用户在手机上实测 Jev 视频后确定；实现见 `videos/jev/film.html` 的 `SAFE`）：

| 项 | 尺寸 |
| --- | --- |
| 画幅 | 9:16，1080 × 1920，60 fps |
| 内容安全区（宽） | 中间 80%：x 108–972，宽 864；背景铺满整幅 |
| 内容安全区（高） | 避开顶部约 12%（y < 230）与底部约 15%（y > 1630） |
| 封面 | 9:16，1080 × 1920；主要内容放在中间 3:4 的范围内（y 240–1680），信息流按 3:4 裁切 |

- **为什么留左右安全区**：全面屏手机约为 9:19.5 到 9:20，播放页把 9:16 的视频按高度铺满屏幕，左右各被裁掉约 9–10%（1080 宽里每边约 97–108 px）。标题、图形、字幕都要放进安全区，不能贴着画面左右边缘。
- 做法：按 1080 宽正常排版，再把全部内容整体缩到 80% 并水平居中；不改画幅，不用 3:4 或 9:19.5。
- 交付前按 886 × 1920（居中裁切）导出一帧预览，确认内容没有被切。

## 正文阅读页

- 电脑端博客正文截图式排版，1080 × 1920 竖版 PNG（9:16；2026-10-01 用户认为 1080 × 1440 过矮后改）；纯白底、左对齐，无浏览器外框和海报装饰。
- 左右边距约 72px，顶部约 62px；章节标题约 50px / 600 字重，正文约 36px / 1.58 行高，段间距约 22px；字体优先系统无衬线与 PingFang SC。（2026-09-29、09-30 两次按用户要求压缩页数，由 40px / 1.68 → 36px / 1.62 → 34px / 1.56；2026-10-01 改为 9:16 后用户要求略放大，回到 36px / 1.58）
- 页眉：左侧文章标题、右侧 `luca’s blog`，约 26px 辅助灰，下接细分隔线。页脚：当前章节与连续页码，细线分隔。
- 链接蓝灰色；引用为蓝灰文字加细左边线；重点适量加粗。文末“参考”一节不输出（图片中链接无法点击，用户 2026-09-29 要求去掉）；正文里的出处链接与引用保留。
- 按语义与完整段落分页，完整保留原文标题层级、顺序与信息，不删减正文。可加简短页面小标题，但不能替代原文章节标题。
- 编号章节大标题（“一、二、三……”）逐字保留，在该章首张图片的正文区域醒目展示，位于页首，且与本章首段或首图同页；不截短、不降级、不拆页。
- 插图保留原比例、就近排版，图注用小号辅助文字；不以缩小整页容纳溢出内容。

## 生成器

正文页由仓库内的生成器自动排版导出，不再每次手写 HTML：

```bash
npm run dev                                   # 另开一个终端保持运行
npm run xhs -- <slug>                         # 导出正文页、标题清单与 ZIP
node scripts/xhs/contact-sheet.mjs <slug>     # 生成整套缩略总览 preview.png
```

- 新文章先在 `src/xhs/articles.ts` 登记（复用文章的 `<slug>.blocks.tsx`：正文、标题与图表映射）。浏览器打开 `/xhs.html?slug=<slug>` 可直接预览全部页面。
- 排版复用站点的 Markdown、KaTeX、Shiki 与自绘图组件；样式在 `src/xhs/xhs.css`，分页逻辑在 `src/xhs/paginate.ts`。
- 分页规则（2026-09-30 用户反馈拆分过碎后调整）：按语义分组装页，标题、以冒号结尾的引导句与下一块同组，图或表与紧随其后回指它的段落（“上图……”）同组，整组放不下就整组换页；放不进一页时组内的图适度缩小（自绘图不低于 90%，表格与论文原图不低于 78%）；整组换页会让本页留白超过 45% 时改为逐块排入。二级章节在本页剩余空间不足 35% 时才另起一页，否则紧接上一章排入（2026-09-30 用户要求压缩页数后放宽）。代码块不拆；段落只在自身高于页面 40% 或本页剩余超过 40% 时按句拆；列表只在本页剩余超过 30% 时按项拆。自绘图缩小时按宽度缩 SVG，缩后实测是否放得下。
- 自绘图在导出时处于紧凑模式（`figure-kit` 的 `CompactContext`，导出页设为 true）：各图提供约 520 宽的竖排布局，导出时 SVG 宽 880px（约放大 1.7 倍），图内文字约 20–24px。新文章的自绘图也应提供紧凑布局，否则图内文字只有正文的一半左右。
- 导出校验：分页前后正文文字逐字一致，否则导出失败；`outline.json` 记录各级标题所在页码，终端列出章节起始页与被缩小的块。
- 输出在 `xhs/<slug>/`（已 gitignore）：`01.png…`、`outline.json`、`preview.png`、`<slug>-xhs.zip`（仅含正文页）。

## 发布内容

一条笔记是“封面 + 视频”或“封面 + 正文页”，三样东西都按文章 slug 找，各只有一个版本：

| 内容 | 位置 |
| --- | --- |
| 封面 | `covers/<slug>/` |
| 视频 | `videos/<slug>/build/<slug>.mp4` |
| 正文页 | `xhs/<slug>/<slug>-xhs.zip` |

`npm run xhs -- <slug>` 导出正文页后会列出该主题的封面与成片路径。

## 核对

导出后查看 `preview.png` 与每个章节起始页，确认标题完整醒目、无截断与异常空白；图内文字在手机上是否清楚；ZIP 页数与导出页数一致。

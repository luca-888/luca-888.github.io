# 封面与头图

### 封面

- 用户要求生成文章封面时，默认输出 **9:16 长竖版（宽:高）**，替代旧的 3:4；用户说“16:9 竖版”时按竖版意图理解为宽:高 9:16。只有明确要求横版时才输出 16:9 横版。多风格样稿也遵循此比例。（2026-10-02 用户再次确认）
- **中英文都要有，中文为主体**：中文主标题最大、英文辅标题较小；保留用户指定的模型名副标题（如 DeepSeek V4），不要做成纯英文封面。（2026-10-02 用户确认）
- **文字安全区**：顶部约 12% 不放文字，左右至少约 6% 边距，避免平台裁切或 UI 遮挡；主体可以铺满下部，不能靠把标题贴顶来减少留白。交付时核对实际像素尺寸和比例，工具返回近似比例时如实注明，不能将提示词中的目标尺寸当作实际尺寸。

文章头图遵循同一方向：

- 每篇结合主题与用户参考单独设计，适度变换配色、构图与图形语言，不套模板；新风格先出样稿确认。
- 视觉冲击来自主体造型、构图、尺度对比与光影层次；可以用深色背景加克制的强调色，不靠发光、金属字或堆叠特效。
- 文字是主视觉之一：素净平面大字，拼写准确、轮廓完整。
- 具体硬件用真实照片或官方渲染，不用 AI 仿造的写实硬件；软件与算法主题用计算关系、执行轨迹、色块或半透明叠层表现。

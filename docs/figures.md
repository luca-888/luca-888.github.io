# 图表

文章自绘图、原图、性能图的规范。

### 图表

- **图要比一段文字解释得更清楚才画。** 一篇文章几张核心图即可，每张图只回答一个问题，图、正文、图注不重复。
- **用图形本身编码数量与关系**：面积、长度、位置、连接。优先用具体小例子，并突出一条完整的示例路径（例如一个 token 的地址翻译）。
- **视觉风格**：实心语义色块（`figure-kit` 的鲜明配色，2026-10-01 选定）、白字或直接标注、清楚的分组与留白；同一概念在全文沿用同一颜色。配色按内容选择，可以鲜明，不受站点 UI 的低饱和配色限制。参考 [vLLM CPU Overhead](../content/vllm-cpu-overhead.md) 的自绘图：进程用 `Band` 淡色底带，示例路径用 `Link focus` 与 `Badge`，编号放在线旁边；箭头终点写在目标边上。
- **有合适的原图就用原图**：从论文源文件、官方 PDF 或源文件取高分辨率版本，原样使用并注明来源，记录在对应 `src/assets/<slug>/SOURCES.md`。
- **技术实现**：自绘图用 React + SVG；性能图用 ECharts（SVG renderer）；数学表达式一律 KaTeX（SVG 内用 `foreignObject`）。
- **交互**：只有参数变化或过程演化确实需要时才加，核心结论默认可见。
- 表格复用 `src/styles.css` 的 `.table-scroll`；分组表头用 `.benchmark-table`。

更多参考见 [技术图表参考](visual-references.md)。

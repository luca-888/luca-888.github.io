# 文章视频

- **与正文同源、不同构。** 事实与数据和正文一致，结构按视频的节奏重新组织，不逐段复述。
- **让画面讲道理。** 能用真实数据就用真实数据，按真实比例呈现；示意内容要标明。
- **讲清机制。** 让观众看到具体发生了什么、为什么，而不只是结论。
- **开头和内容连起来。** 开头的视觉自然过渡到第一个论点，而不是与内容无关的封面。
- **少字。** 一个画面讲一件事；科普口径，不放测量限定和方法说明。
- **画面单独设计，色彩与风格保持一致。** 按主题设计画面构成与节奏，色彩和整体风格沿用系列，不大幅更换。
- **看成片检查。** 在目标观看尺寸下确认文字清楚、无裁切、转场顺畅。

# 静态导出

## 保留与降级

| 内容 | 默认处理 |
| --- | --- |
| 标题、正文、列表、链接 | 保留 Markdown 结构；参考链接保留公开 URL |
| 代码 | 保留 fenced code 与语言标记；不转截图 |
| 简单行内公式 | 能无歧义表达时改为普通符号或行内代码；否则保留公式并在实际导入后验证 |
| 独立公式 | 优先稳定可读；可由 KaTeX 渲染为 PNG，避免编辑器公式兼容问题 |
| 简单表格 | 可保留原生表格；导入不稳定时用静态图片 |
| 分组表头、宽表 | 从真实数据渲染 PNG，保留单位、表头、完整行与必要注释 |
| React/SVG 计算图 | 导出全部关键状态，如 Forward / Backward 各一张 |
| ECharts 图表 | 关闭动画、选中态和缩放控件；关键指标直接显示；用实际数据导出 PNG |
| 滑杆、悬停、切换、折叠 | 展开有信息量的状态；其余删除，并同步改写“点击、拖动、悬停”等正文 |
| 长代码/原始测量记录 | 正文保留核心；完整资源用已存在、可访问的仓库/下载链接 |

不添加 benchmark 方法或环境说明等原文章有意省略的内容。图表色彩、文字、单位与当前项目约定一致。性能数据直接来自本次源码快照对应的真实 JSON，不重新测量或混用旧稿。

## 含组件的博客

1. 读取当前正文及渲染入口，列出 `::component::` 等所有自定义标记。每一个标记都必须有静态替代或明确删除。
2. 为本次导出复制所需源码、数据和样式到临时目录。使用独立端口、缓存目录和入口加载文章；不要修改首页或发布配置。
3. 在桌面视口渲染，截图取组件/图表区域而非整页。通常使用 2× 像素密度，保持文字可读，不保留无作用的按钮。
4. KaTeX 截图必须等字体加载完成；确认字体请求没有 403/404，且 `document.fonts.check('16px KaTeX_Main')` 为真。只等待页面空闲不能证明字体加载成功。
5. 若使用 Vite 的独立快照，显式配置临时 `cacheDir`；依赖通过链接复用时，`server.fs.allow` 应仅允许该快照和所需依赖路径，避免字体被拒绝。
6. 导出 ECharts 时优先在快照内关闭 dataZoom/tooltip/选中态。不要随意从另一条模块 URL 再导入 ECharts 获取实例，否则可能得到不同实例注册表。
7. 各切换状态分别截图。用实际组件所属区域定位按钮；多个比较区可能共用 CSS 类，不能只用一个宽泛类名取表格。
8. 将截图插入静态 Markdown，修订衔接文字。标题、表格数据、代码与完整章节都要保留；不必为每一个删除的交互添加解释。

## 已验证的 RMSNorm 示例

首次适配的项目是技术博客 `ml-portal`，正文为 `content/rmsnorm.md`。这些是定位线索，不是固定数量或永久文件结构，后续使用时重新读取当前文章：

- `::rmsnorm-demo::`：可删除开头滑杆演示，并删除“调整输入与权重”的提示。
- `::rmsnorm-graph::`：Forward 计算图和 Backward 梯度流分别导出。
- `::rmsnorm-benchmark::`：BF16 eager 基线表。
- `::rmsnorm-timeline::`：Forward、Backward 两张静态时间线；删除缩放滑块与 kernel 选择器。
- `::rmsnorm-eager-ops::`：可删去折叠长清单，保留紧邻正文对拆分行为的解释。
- `::rmsnorm-compile-benchmark::`：将 Forward/Backward 页签展开为两张表。
- `::rmsnorm-compile-graph::`、`::rmsnorm-triton-graph::`：保留静态执行结构图。
- 原始编译代码折叠区可删除；完整源码通过资源链接提供。
- 第四章与第三章的 compile 基线若来自不同测量，保留现有的简短差异说明。

## 检查与交付

- 所有 Markdown 图片引用解析到实际 PNG；图中数字与对应数据一致，图中文字未裁切。
- HTML 预览能够离线显示全部图片。可将 PNG Base64 内嵌到 HTML，但网页导入仍使用本地图片上传。
- 无残留组件标记、正文中的失效本地下载链接或仅靠交互才能理解的段落。
- 运行 `prepare_uploads.py` 生成导入稿和定位清单；有原始 Markdown 时用 `--source` 对比 fenced code。
- 将正文、预览、assets、导入稿和清单一起打包。无需运行整个博客的生产构建或重新执行 GPU benchmark。

# 知乎网页导入、补图与发布

适用于浏览器自动化或 agent 操作电脑。2026-09-15 用户截图确认：写文章工具栏有“导入 → 导入文档（MD/Doc）”和“图片”按钮。页面可能更新，先读当前屏幕/可访问性树，用文字和控件角色定位，不硬编码屏幕坐标。

## 1. 进入正确的编辑器

- 打开 `https://zhuanlan.zhihu.com/write`，复用已有登录状态。
- 如果是更新已有草稿/文章，先打开用户指定地址并核对标题；不默认新建另一篇，也不清空不相关草稿。
- 需要登录或验证码时由用户完成，不读取或索取 Cookie、密码。
- 上传文件必须存在于浏览器/电脑工具所在机器。工具运行在另一台机器时，先把导出包放到该机器的用户可访问目录，再重新生成清单中的绝对路径；远程容器路径不能直接填进本机文件选择器。

## 2. 导入正文

推荐从 `upload-map.json` 取得 `title` 与 `web_import_path`：

1. 填写顶部“请输入标题”栏。
2. 点击工具栏“导入”，选择“导入文档（MD/Doc）”。
3. 通过文件选择器上传 `*-web-import.md`。浏览器工具支持文件选择器时使用它；仅能操作桌面时在系统对话框中输入完整路径。
4. 等待正文解析完成，核对第一段、最后一段、章节与图片占位符均出现。

导入入口不可用时，可将 `*-web-import.md` 的纯文本粘贴到正文。若出现 Markdown 识别提示，点击“确认并解析”或“立即转换”。此导入稿已删除一级文章标题，不应在正文顶部再出现一次标题。

不要整段复制 HTML 源码。离线 HTML 内嵌的 Base64 图片不是已上传的知乎图片。

若导入的是有实际图片引用的旧稿，可能出现“上传失败”。先对照原稿找到该块对应图片，随后按下一节修复；不要直接重新导入全篇造成重复正文。

## 3. 按定位清单逐张补图

按 `upload-map.json` 的 `images` 数组遍历，而不是按文件夹排序。每一项包含：

- `token` / `placeholder`：唯一正文定位标记。
- `absolute_path`：应上传的实际 PNG。
- `context_before` / `context_after`：定位失败时用于核对位置。
- `sha256`、宽高：确认素材没有变化或拿错。

对每张图执行：

1. 找到对应占位段落，如 `【配图 ZHIMG-001｜RMSNorm 定义】`，滚动到可见。
2. 将编辑光标放到该段落旁的独立段落，点击工具栏“图片”，选择清单中的 PNG。浏览器的查找栏只能帮助滚动，不能把它误当作编辑器光标。
3. 等待图片上传并在正文中显示，确认既无失败状态，也无加载占位。用预览/清单核对图片内容。
4. 上传成功后再删除该唯一文字占位段落；保留图片、图注及相邻正文。先上传再删除标记，便于失败时继续定位。
5. 记录该项完成，进入下一项。中断后根据页面中剩余标记恢复，不重导正文或重传已完成图片。

若旧稿已有失败图片块：用章节和上下文确定对应素材，删除该失败块，在同一位置上传 PNG。不要把所有图片都追加到文末。

优先使用正常编辑器按钮和上传流程；可用 DOM/可访问性信息定位，但不要直接改内部 React 状态或仅写 `innerHTML`，那可能不会被编辑器保存。

## 4. 检查保存结果

- 标题栏正确，正文没有重复标题。
- 每一个预期位置有对应图片；没有 `ZHIMG-`、`上传失败`、`assets/xxx.png` 等残留文字或失效块。
- Python/Triton 代码保持代码块、缩进与完整内容，必要时手动选择 Python 语言。
- 对照预览核对四类内容：章节、公式、表格、代码；具体数量来自本次清单，不固定为首次示例的 14 图/4 段代码。
- 等待自动保存状态成功，然后重新打开草稿确认图文仍在。仅看到编辑器当下内容不代表已保存。
- 保存/提交状态不明时，先检查当前草稿或文章列表，不盲目再次点击发布；单个上传失败可重试一次，仍失败则保留草稿与剩余清单并报告阻塞位置。

## 5. 发布与更新

- 当前用户明确要求正式发布：检查通过后执行页面实际提供的发布流程，按要求选择相关话题；提交后打开最终文章地址确认标题、关键图表与正文。
- 当前请求仅导出/导入/草稿：停在该阶段并交付文件或草稿地址，不自行扩大到公开发布。
- 更新已有已发布文章：确认修改的是目标文章，使用编辑器的更新/发布修改流程，验证原 URL 的内容；不删除原文后重发。
- 无需因 skill 本身再加一次固定确认。登录、验证码、缺少目标文章或无法判断当前内容归属时，才向用户索取必要信息。

用户偏好简短回复：完成后给文件/文章链接及一行结果。失败时指出具体图片/步骤和已经保留的进度。
